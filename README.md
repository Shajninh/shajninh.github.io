# Shajnin Howlader Portfolio

## Brief Description

This project is an interactive personal portfolio website designed to showcase my projects, experience, and technical skills. The website uses an interactive flashlight experience where users explore a dark scene and click on different objects to view additional portfolio content.

## Technologies Used

* HTML
* CSS
* JavaScript

## Deployed Website Link

https://shajninh.github.io

## How to Run the Website Locally

1. Clone or download the project repository.
2. Open the project folder in your code editor.
3. Make sure all HTML, CSS, JavaScript, image, and audio files are in the correct folders.
4. Open `index.html` in a web browser.

For the best experience, run the project using a local development server such as the Live Server extension in Visual Studio Code.

## Challenges

One of the main challenges was creating the interactive flashlight effect while keeping the background scene hidden until the user selected a flashlight. I also had to coordinate multiple layers, including the background image, dark overlay, mouse-following light, and clickable objects.

Another challenge was creating clickable areas over specific objects in the background while ensuring that users could navigate to additional content and return to the main scene.

These parts required me to utilize Claude AI for assistance in coding.
